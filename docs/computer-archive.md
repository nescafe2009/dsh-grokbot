# Computer 归档作品库

Computer 默认显示按归档时间排序的项目卡片。项目名称、归档时间、成员组合头像、摘要和成果数量构成一级信息；网页成果提供直接打开入口。支持按项目、摘要与成员搜索，另有最近成果视图和工作区入口。

项目详情提供归档前的交付快照、同一源文件的历史版本、阶段验收记录及原会话入口。主要文件优先显示，超过八份时其余折叠。没有交付快照的项目仍可浏览摘要与原会话。文件关联仅采用元数据中的 conversationId，不按姓名或相似路径猜测。不同源路径的同名文件保留为独立成果；缺失 payload 不生成预览按钮。

归档时间作为成果截止点，归档后的快照不混入。验收状态使用冻结计划和有效验收指纹计算，不从阶段标题或成员自述推断。界面明确区分归档与验收；没有归档时有效验收记录会显示未确认。读取失败会显示说明，不默默展示空列表。

本页为浏览入口，没有恢复、归档、取消或验收操作。用户继续与幕僚长对话管理项目。浏览、搜索、预览和版本展开不会修改历史任务或启动 Bot。
