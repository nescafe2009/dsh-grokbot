# 对话与执行体验更新

2026-09-10，本地候选版本，尚未创建新 GitHub release。

对话是团队操作入口。群聊任务面板只用于查看阶段、负责人、依赖和验收状态；“查看/隐藏任务进展”由会话顶部统一控制，不再另设面板折叠按钮。原 × 改为带“返回会话首页”标签的返回按钮。点击任务负责人进入成员对话，可展开执行进展。

字号统一为辅助 12、标签 14、正文 15、标题 18、展示标题 26 像素；保留现有中性底色与角色辨识。侧栏头像扩大到 44、会话头像 48 像素，工作状态带轻微动态，遵循系统减少动态效果偏好。编辑资料区分名称、职位、专业模板及补充职责，读取当前补充职责与模型配置；保存姓名不能重置模型。

执行记录展示可见进展、工具调用与配对结果、文件修改输入、错误、派工与交付、工作检查点。最近 25 项派工、每项最近 80 条事件；工具输出有长度上限。当前已加载会话也可查看最近执行事件，历史未保存的数据不补造。排除 reasoning 内容，常见凭据字段脱敏。记录是实际执行证据，不替代独立验收。

聊天输入框以单个相机菜单提供 5 秒、10 秒延时整屏截图及立即区域截图。延时由后台原生截屏执行，点击后可打开菜单栏弹窗，无需回到聊天窗口；倒计时可取消。也支持 macOS Control + Shift + Command + 4 截图到剪贴板，再 Command + V 粘贴 PNG。先在草稿中预览或移除，再由用户发送。截图快照存于本地运行目录，不进源码或发布包；会话切换时不会把迟到截图塞入另一会话。截图取消不发送消息；超时/权限拒绝给出明确提示。非 macOS 返回暂不支持说明。

滚动监听按会话保持稳定，更新通过单个动画帧合并；手动向上阅读时立即暂停跟随，不因轮询重建监听。关闭聊天容器的浏览器滚动锚定，Markdown 使用稳定键值。

生命周期操作被拒绝时如实保留原因，不把业务拒绝当作模型回复失败。只有同一项目已实际派发后续任务时才展示补救说明，绝不据此登记复测或验收通过。

重复审批首先从减少非必要越界解决：角色规范要求 Swift/Clang 缓存位于项目 .build 目录，并在失败后分析错误而非重复命令。审批卡解释对象与单次有效期。没有将用户先前的“允许一次”变成长期授权；长期授权仍使用 DSH 宿主机制。这不保证所有构建审批消失，确需联网或越界的操作仍走正常审批。

输入框改为上方多行文字、下方截图与发送工具栏，统一外层聚焦提示，保留按钮键盘焦点。完整保留末尾空格与换行；机器人回复期间可准备文字和截图。发送仍等待当前回复完成，提示该状态；中文输入法确认和 Shift + Enter 不触发发送。
