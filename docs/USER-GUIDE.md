# DeepSeekBot 试用手册

版本0.6.0；包名仍为dsh-grokbot。本项目与DeepSeek官方无隶属关系。先读[安装说明](INSTALL.md)。

## 开始一个小项目

先在DSH配置自己的模型服务并验证对话，再进入幕僚长：

> 在我指定的试用目录做一个简单静态网页，先说明范围和验收标准，开发后交测试，不发布到外网。

明确目录、修改范围和交付要求。首轮用不涉及真实业务数据的小任务，避免直接授予全部机器权限。

## 用对话管理

幕僚长组织分工和交付。可以问“现在谁在做什么，卡在哪里”，也可以说“某项目验收未通过，按钮无效，修复后重新测试”。查看交付并实际验证后再回复通过；多项目时明确名称。

暂停保留记录，不保证正在运行的外部工具瞬间停止；继续前核实阻塞解除。复盘生成有证据的评分与建议；归档收起项目并保留历史，不代表所有工作自动通过。后续优化原产品使用原项目新迭代。

## 进展与日志

成员的工作进展入口显示任务和工具输入输出。排队不等于执行，执行结束不等于验收通过；失败、取消、待复测、待验收分别处理。

同bot及共享工作区有互斥，幕僚长长回合可能让其他任务等待。不要重复派任务或随意重启催进度。成员项目隔离和动态补员由生命周期与调度规则约束；共享工作区仍可能排队，应以工作详情中的实际状态为准。

## 模型与授权

团队设置可维护常用模型、按成员快速选择。成员模型优先于团队默认，修改用于后续请求，不保证改变在途任务。服务连接和API key在DSH配置，不能交给bot写入记忆。

审批前核对目标、命令和影响。“允许一次”只针对当前操作；记住规则时核对成员、会话、目录及期限，可撤销。原生宿主审批仍可能出现。插件不是安全沙箱，团队成员不得修改 DSH/DeepSeekBot 自身代码、权限、调度或评分机制；该边界仍依赖宿主权限和审批，请勿授予无关目录访问。

## 截图与动效

macOS输入框支持截图附件，首次可能需要屏幕录制权限。选择器可能影响菜单等临时界面，快捷键和平台支持以实际界面为准。发送前检查附件中的私人内容。角色动作可减少或关闭。

## 复盘与成长

说“复盘某项目”，在Computer复盘档案回看结果。评分是已有证据的评价，不是能力认证或模型训练；样本少、高分或写了报告都不等于能力提升。建议需在后续项目验证。本版没有按评分自动招聘与派难题的完整闭环。

## 排障

| 现象 | 处理 |
| --- | --- |
| 无回复 | 看bot和工作区是否忙、模型连接是否成功；不要重复派工。 |
| Insufficient Balance | 处理服务余额或更新凭据，失败复测仍需完成，不能直接通过。 |
| 401/403 | 检查服务连接与宿主权限，不分享整个凭据文件。 |
| 归档后还显示 | 查看排队或失败原因，用独立一句“归档当前项目”明确目标；混合其他项目否定语句的识别有限制。 |
| 恢复会话失败 | 保留数据，记录版本和脱敏错误；本版不会静默新建会话掩盖恢复失败。 |
| 执行结束却未验收 | 核对独立复测结论和当前版本，不手改生命周期JSON。 |

## 试用反馈

建议完整走一次小项目开发、独立测试、驳回修复、验收、复盘、归档。未做的场景写“未验证”。

GitHub issue请注明插件版本、DSH版本、系统架构、复现步骤、预期与实际结果、时间和脱敏截图。勿上传状态目录、原始会话、API key、token或个人备份。
